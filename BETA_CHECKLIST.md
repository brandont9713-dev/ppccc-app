# PPCCC Beta Checklist

## Website And Content Access
- [ ] Ask the church website owner for FaithConnector admin login access.
- [ ] Ask FaithConnector support if the site has API, webhook, RSS, XML, JSON export, or custom form action support.
- [ ] Ask whether public page polling into an app cache is allowed if no API/webhook exists.
- [ ] Ask Teamup calendar admin for a write-capable API key and subcalendar IDs.
- [ ] Ask YouTube/media admin for the channel ID, uploads playlist ID, and live stream source.
- [ ] Ask what giving provider/link should be used for tithing.

## Beta Testing
- [ ] Install latest TestFlight build.
- [ ] Test Home, More, Events, Live, Kids Korral, and Settings on iPhone.
- [ ] Test layout on iPad.
- [ ] Create a beta account on-device.
- [ ] Link one Kids Korral number.
- [ ] Link multiple Kids Korral numbers.
- [ ] Add an event to Apple Calendar.
- [ ] Submit a prayer request.
- [ ] Submit a signup/form.
- [ ] Play sermon videos in-app.
- [ ] Enable notifications.

## Production Readiness
- [ ] Connect real Supabase Auth.
- [ ] Enforce admin and Kids Korral roles on the backend.
- [ ] Connect form submissions to the same destination as the website.
- [ ] Connect Teamup write API for admin calendar edits.
- [ ] Connect licensed CSB daily verse source.
- [ ] Add privacy policy and support URL for App Store review.
- [ ] Run final security and legal review before public release.
